# Logo Elektro Dvořák

## Umístění loga

Vložte sem soubor loga:
- **logo.png** - Logo s bobrem (doporučená velikost: 200-300px na šířku, transparentní pozadí PNG)

Aktuálně web hledá logo na cestě:
```
assets/images/logo.png
```

## Formát
- **PNG** (doporučeno - podpora průhlednosti)
- **SVG** (ideální pro škálování)
- **JPG** (pokud nepotřebujete průhlednost)

## Rozměry
- Šířka: 200-300px
- Výška: automatická (zachová poměr stran)
